## Description
Foundation for the context-bounded artifacts epic. Introduce one reader layer ("docset") that maps a logical design document (DECISIONS, STATE, ARCHITECTURE, BUILD, attestations) to either a single legacy file or a directory of entry shards plus a generated INDEX, and route every gate that opens those files through it. Citations (row:<path>#<section>#<key>, section:, file:, idcite, attestation covers, ledger reads) resolve by stable id through the docset, so the shard an entry lives in is not part of its address.

Acceptance criteria:
1. A logical document reads identically (same parsed rows, same gate verdicts) whether stored as one file or as shards; a parity test runs the gate suite over both layouts of each example design.
2. The shard format is defined in docs: directory name, entry file naming (stable id + slug), INDEX format (id, title, file, bytes, one line each), ordering rule.
3. INDEX is generated by machinery and drift-checked on every check (a hand edit or missing entry is DRIFT); an INDEX over the file budget splits hierarchically.
4. Every existing citation form resolves by id in both layouts; a citation to a moved entry still resolves; a duplicate id across shards fails naming both files.
5. Design-lock and snapshot code treat a docset directory as one subject (attest covers, publication transactions).
